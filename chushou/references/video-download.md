# 从链接取得原片

输入可以是短链接、完整播放页、直接媒体URL，或带口令／标题的分享文案。此入口用于用户要求的视频复刻／分析，不因任意普通网页链接触发图片生成。

红果短剧另有已移植的fruitknife原生入口：剧名搜索、分享链接／`series_id`解析、选集、360p—1080p清晰度与逐集续传，详见 [fruitknife-download.md](fruitknife-download.md)。先走该入口，不把整部剧链接交给普通单视频提取器或第三方解析站。原有抖音等下载路径保持可用。

## 本地入口

使用现有Python运行时调用 `scripts/download_video.py`。公开包不附带运行时或二进制。先定位当前宿主Python；视频检查需PATH或显式路径中的FFmpeg，播放页下载还需官方yt-dlp。已有依赖直接复用，缺失时说明所需安装项，不假定作者机器目录。

将原始分享内容以UTF-8保存为项目内 `source-link.txt`，通过文件参数传入，避免把用户文案中的引号、美元符号或反引号拼成shell代码。

```text
python scripts/download_video.py --source-file "项目/source-link.txt" --out-dir "项目/downloads"
```

- 默认下载单个完整视频，选取可取得的最高画质并保留其音轨；不批量下载整个账号或播放列表。只有源视频本来无声时按无音轨记录，不将仅画面流或仅音频当成完整视频。
- 直接媒体走HTTP流式下载；播放页走官方yt-dlp。使用隔离依赖，不修改玄念、系统代理或浏览器凭据。
- 校验真实视频流、时长与分辨率、文件哈希和完整解码，拒绝HTML／JSON假媒体、封面、空文件以及可判定的试看／DRM结果。
- 同一请求仅在本地文件和哈希仍有效时复用；其他情况创建新目录，不覆盖已有原片。失败结果保留在该次目录中，状态不标成成功。
- 默认自动衔接 `inspect_video.py`，输出元数据、带时间的帧、联系表和原片有声时的16kHz单声道音轨。`--download-only` 仅用于用户只要下载，或准备后续另行精确抽帧时。
- 从标准输出取得 `video`（真实本地视频路径）、`manifest`、`analysis` 及 `inspection`，再查看实际帧、核对台词、写用户要求的提示词。不能只总结标题、封面、网页文案或转录。

## 玄念解析站回退

已将玄念9.1.8 `src/media-library.js` 的实际九平台路由导入 [video-platforms.json](video-platforms.json)，包括抖音、TikTok、哔哩哔哩、小红书、快手、YouTube、Instagram、X、Facebook。该文件是路由信息，不是保证所有链接可下载的声明。原实现使用Electron页面与IPC，不能伪称有现成HTTP下载API。

1. 网页提取器失败、要求新会话或找不到可下载格式时，按匹配平台的 `portals` 顺序打开主解析站，无法取得结果时尝试列出的备用站。普通公开链接的下载及解析已在用户本工作流授权范围内，不再逐阶段询问。非公开／带访问凭据的链接不要擅自交给第三方。
2. 浏览器交互只用当前可用的Codex浏览器工具。读取实际页面后，填写链接并点击真正的解析按钮。**不要执行玄念旧版 `executeJavaScript` 自动化字符串，不用浏览器evaluate修改页面、调用隐藏接口或读取浏览器凭据。** 旧实现的网页选择逻辑可作参考，但现场DOM才是控件与结果的依据。
3. 从实际显示的结果确认标题、视频预览和画质。选择最高可用的完整视频；站点确有原片无水印候选时可选该候选，不用裁切、修补或重绘去除叠加内容。视频与图片、封面、音频候选必须区分。不要点击广告、弹出的安装项或购买额度。
4. 优先读取结果中真实视频元素／下载链接的 `src`／`href`，把实际媒体地址传给同一个下载器。没有直接地址但有真实浏览器下载时，使用浏览器提供的下载方法取得文件，再校验并分析。媒体签名URL只用于当前下载，不把它们打印进聊天或当作可长期复用的来源；长期记录保留用户分享源URL。

```text
python scripts/download_video.py --source-file "项目/source-link.txt" --media-url-file "项目/resolved-media-url.txt" --referer "解析站或实际需要的源站地址" --out-dir "项目/downloads"
```

5. 遇到验证码、登录、二维码、被删除或权限限制，记录实际阻断并仅请求必要的用户操作。不绕过付费、DRM或访问控制；不声称已取得完整原片。正常网络错误允许有限重试，主／备用路径均失败后说明具体原因，不无限试站或反复提交。

## 后续制作

下载成功后继续主技能的镜头、对白、表演、硬切、空间关系与后期效果核对。图片仍默认用Codex内置，已有资产复用；道具先核对，生成视频仍须用户明确提出并确认具体信息。输入从文件改成链接，不改变这些约定。
