# 本地视频检查

`scripts/inspect_video.py` 完成元数据读取、抽帧、联系表和音轨提取；不修改源视频、不联网、不自动安装依赖。

需要Python与FFmpeg。先检查现有运行时；Codex桌面可用工作区依赖定位工具找到Python。FFmpeg可来自PATH、已安装的imageio-ffmpeg或显式路径。ffprobe可选，缺失时解析FFmpeg报告。Pillow可选，只影响联系表。

```text
python scripts/inspect_video.py --video "参考视频.mp4" --out-dir "项目输出/analysis"
python scripts/inspect_video.py --video "参考视频.mp4" --out-dir "项目输出/cut-check" --timestamps "6.4,6.5,6.6,6.7" --no-audio
python scripts/inspect_video.py --video "参考视频.mp4" --out-dir "项目输出/analysis" --ffmpeg "FFmpeg可执行文件路径" --interval 0.5
```

- 默认每1秒抽帧只用于总览。快速动作和短句可能完整落在两个采样点之间，不能以此完成复刻观察。
- 输出 analysis.json、帧图片、Pillow可用时的联系表，以及有音轨时的 audio.wav（16kHz单声道PCM）。重复运行创建独立run目录，不覆盖前次输出。
- 请求seek时间是抽帧定位依据，不等于已人工核实的精确切点。ffprobe缺失时精度以FFmpeg报告为准。
- 联系表只用于总览；脸、口型、服装细节及对白字幕看清晰单帧。
- 脚本不自动判断说话人、台词、硬切或后期定格，需要结合画面与可用音频核实。
- 本地转录应保留不确定词，并结合字幕和口型纠正；不能将ASR猜测当作确定台词，不能在无法听音时声称已听过。

## 连续动作复核

`scripts/inspect_motion.py` 复用既有analysis.json中的源文件、真实视频流与FFmpeg路径，从源视频连续解码选取指定区间；通过select选帧、showinfo记录实际解码PTS，输出原分辨率图片和带PTS的联系表。它不采用插帧补帧，也不将请求seek时间冒充实际画面时间。

```text
python scripts/inspect_motion.py --analysis-file "项目/analysis/run目录/analysis.json" --range 0:15:10 --range 15:69:5 --out-dir "项目/motion-review"
python scripts/inspect_motion.py --analysis-file "项目/analysis/run目录/analysis.json" --range 6.1:7.3:30 --out-dir "项目/contact-check"
```

`--range`是开始秒:结束秒:采样fps，可重复；原视频30fps时30代表逐帧。联系表用于按序观察，形态／皮肤／服装／材质需打开清晰原尺寸帧。

- 先覆盖全片，再逐镜检查起始、动作中段及结束。记录所有真实出现的主体，不用字幕或既有资产清单代替观察。
- 快速扑击、抓走、咬甩、碰撞、飞行与短时出场按6–12fps复核；接触点、遮挡和切点前后约0.5秒按原帧率补看。采样频率由动作速度决定，不把固定1fps当最终证据。
- 写清动作链：起始位置→移动方向→接触对象与部位→形变／失衡→飞离／落地／后续反应。物体被打飞后才看见施力者时，保留遮挡和出场次序，不提前展示主体。
- 摄影机变化与主体动作分开记录：手持起伏、倾斜、后退、急甩时的运动模糊、重新稳定的方向。甩镜模糊、物体遮满镜头和真实曝光变化不自动算硬切或后期转场；检查前后空间连续性。
- 质感从清晰帧提取光源、色谱、毛发／鳞片／膜翼／湿表面、粒子与烟尘；动态从连续序列提取速度、受力和节奏。不得仅用通用电影风格词掩盖未看清的对象。
- 复核完成才更新分镜、资产清单和引用映射。证据不清楚时保留有限且具体的可见描述，不补造物种身份、额外肢体或未见动作。

## 逐镜事件记录与独立回看

密集帧解决时间采样遗漏，不能自行保证方向、节奏和因果解释正确。写提示词前为每个真实镜头保存事件记录，连续镜头内按动作阶段分行；这些阶段不是新硬切。可用 [key-event-ledger.schema.json](key-event-ledger.schema.json)，参考 [本片飞虫抓狮的已观察片段示例](key-event-ledger.kunshou-example.json)。示例是局部证据，不代表整镜或全片已经验收；无需为了填表另造识别程序。

每条记录需能回到真实帧：

- **方向与顺序：** 按画面左右／上下记录首次露出的边缘、离开的边缘、移动方向、遮挡以及先后链；镜头横摇引起的屏幕位移另记。头朝哪边、资产图朝向、画面上方出现均不能替代入画侧判断。
- **节奏与接触：** 保留起动、抓牢／撞中、离地／形变、甩出／落地的实际PTS与间隔；写快速掠过、连续冲撞等可见节奏，明确有无停顿。接触未逐帧定位时记录证据上下界和首张已证实接触帧，不能把10fps样本当精确首次接触。遮挡处标明不可见，不补成慢动作或新增准备姿势。
- **机位与冲击：** 单独记摄影机所在位置、摇向、前进／后退和倾斜阶段；自然手持起伏、操作者躲避与碰撞震动附对应时间和可见依据。强度与持续时间依原片，固定机位不能统一改手持，急横掠不能改成稳定仰拍慢降。运动模糊是速度证据，清晰单帧只负责细部。
- **真实资产：** 每镜列可见主体、载具及关键道具，并绑定已有资产ID；尚无独立图的真实道具也登记用途和待确认／随场景复用状态。核对类型与动作接触对象，不用一种飞机替代另一种，也不从角色职业补造道具。记录色谱、光源和材质的清晰帧，避免动态描述正确但主体材质错误。

初稿后另一次从源片／连续帧独立观察，再逐项比对提示词、时间映射和参考顺序；不要只重读初稿或让第二位agent复述第一位结论。可委派独立视觉核查；无并发能力时自身重新看原序列。优先回看短促出场、遮挡接触、甩车／抓走、快速运镜和跨段连续镜头，记录发现的差异并修到对应时间范围。画面能判定就自行处理，剩余疑点局部标注；只有确实影响结果且现有证据不能解决时询问用户。

生成后用同一记录逐镜对照成片：入出画侧、动作链、速度／停顿、接触受力、机位／震动、资产外形／道具、光线材质与对白。列出具体差异及对应源PTS／生成时间，优先局部改词、补参考或可逆剪辑，不让用户从头人工查错；需重新付费生成时沿用技能的具体信息核对要求。自动抽帧与生成可以降低人工干预，不能承诺零遗漏或仅凭参数对齐宣布完全复刻。

工具原理依据FFmpeg官方[select与aselect](https://ffmpeg.org/ffmpeg-filters.html#select_002c-aselect)及[showinfo](https://ffmpeg.org/ffmpeg-filters.html#showinfo)文档；输出PTS也需要视觉核对，脚本不会自动认出动作或切镜。
