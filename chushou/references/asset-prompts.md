# 图片资产规范

## 按目标画风分流

写资产提示词前，依据用户本次要求、已确认项目风格和目标资产的表现形式选择分支，不能仅凭参考图是真人照片就判定最终资产必须真人化。

- **3D／CG资产**：读取随包的 [asset-prompts-3d.md](asset-prompts-3d.md)，完整采用用户提供的3D提取规格。3D人物默认16:9、中性灰底、34%／22%／22%／22%四栏，依次正面面部特写、正面全身、标准90°侧面全身、背面全身；三个全身均保留完整头脚，不能套用下文真人三栏与无头要求。固定国漫风格句同时写入「风格定位」和成品末句，之后不追加真人质感尾句。怪物、场景及其他3D资产按该文件各自结构和项目美术要求，不强套人物四视图。
- **真人资产**：继续使用本文件原有的白底三栏、中央无头及完整真人质感词，下面的真人版式和尾句不变。
- **混合或其他风格**：按每项资产的目标风格分别处理，记录所用分支。纯二维或用户明确指定的其他风格不自动归入3D或真人；遵从其明确风格与版式。

两条分支共用三阶段确认、剧情道具筛选、默认纯文字生图、已有资产复用、生成通道、无人场景、永久保存及真实参考记录规则。新规范不触发已有资产重做；不为了原创差异化改变已确认的复刻身份。用户本次明确模板与要求优先。

## 生成前提与参考输入

资产提示词与视频提示词同属第一阶段，默认确认后才进入第二阶段生图；仅给视频链接不授权自动生图。明确全流程或指定阶段时遵从主技能的覆盖规则，不重复索要已有授权。只更新技能规则不处理实际资产。

新资产默认只把文字提示词送入生图模型。可观察源视频／帧以反推外形、空间和光照，再写成完整文字，但不附源帧、联系表或源帧裁切图；只有用户明确特殊要求才使用指定截图作为图片输入。用户主动提供的人物替换图、明确指定参考及已有确认资产可按要求复用。记录「分析来源」与「实际模型参考」两套信息，纯文字生图的 `reference_paths/reference_node_ids` 为空，不把分析来源伪装成上传参考。

## 默认生成通道

漫剧生产线默认先通过 [production-lines.md](production-lines.md) 中人物／剧情必要道具／场景的适用类别样图确认，再批量生成；用户明确调整确认节点时按其范围执行。已有确认图可充当样图，不为新流程重做；只确认一类不自动批准剩余适用类型，无剧情必要道具则该类不适用。样图、提示词、实际参考、SHA和确认版本一起保存。短视频按默认三阶段或本次明确覆盖要求执行。

默认使用宿主原生图像生成工具（Codex中为内置图像生成）。用户明确指定神思、即梦、LibTV等图片通道，或要求「在神思中进行全流程」时，使用指定平台的真实配置完成资产生成。仅指定最终画布位置或神思当前选中了某配置不改变默认图片通道。缺少配置／权限时说明，不擅自切换；已确认的剧情道具范围不重复询问。

## 真人资产每段必加的质感词

以下整段原样附在每条真人风格的人物、场景、已批准道具提示词的末尾，不能只作为所有提示词共用的总说明；不追加到3D或用户指定其他画风的资产：

```text
真人超写实，可見毛孔細微毛孔質感， candid,low quality,natural lighting with shadows Style Modifiers: Volumetric lighting, Ray tracing, Particle effects, Bloom effect, Hyper-realistic textures, Dynamic angle, Film grain, Cinematic composition
```

固定排版、身份和原片场景优先于风格词。Dynamic angle不能把正面／背面改成侧面；Particle effects、Bloom effect不能擅自新增转场、烟雾或炫光。保留实拍皮肤与织物纹理。用户提供新质感或版式时按新要求。

## 真人人物三视图标准版式

一人一张横向三栏图，通常16:9：

这些版式要求适用于新生成的三视图。用户指定复用的已有图即使裁切不同，仍按已有资产使用；除非用户明确要求规范或修改，不重复生成。

- 左侧：头部特写，包含完整头发、面部及少量颈肩，足够辨认五官和皮肤纹理。
- 中间：正面全身（无头），按颈部裁切，头、脸、下巴、发尾都不进入中央栏；颈根、衣领、双臂、下装及双脚完整。是服装型录式自然裁切，不是断头造型。
- 右侧：背面全身，包含完整后脑、头发、衣服和双脚，严格背向镜头。
- 纯白背景，中间与右侧身体比例一致、脚底齐平，三栏不重叠；不要文字、标签、分隔线、水印或场景背景。
- 文字设定完整写明身份、年龄、五官、发型、服装和已有饰品；确有获准使用的参考图时再用它锁定这些特征。手臂自然下垂，不把原片坐姿、手势或夸张表演强加到全身站姿。
- 原片没有展示下装／鞋款时，仅作朴素同风格补全，并说明该部分是补全；会影响剧情或身份的缺失信息才询问。

提示词骨架：

```text
16:9横向人物设定图。按已确认的完整文字描述写清人物年龄感、脸型、五官、发型发色、体型、服装、配饰和材质。纯白背景，左侧头部大特写，中间正面颈部以下至完整双脚、中央不出现任何头部，右侧包含后脑和双脚的背面全身。三栏为同一人物，身体比例一致，自然站姿和轻微表情，无文字／字幕／水印。附完整固定质感词。
```

仅在本项确有获准的图片输入时，追加对应参考的真实用途；身份图只锁身份与服装，布局图只管排版，不能默认补写不存在的「参考帧A」。

## 场景图（共用约束）

- 一处需要复用的场景一张，无人物、人体倒影、顶部标题、对白字幕、片尾字卡、水印。
- 将观察到的相机位置、主家具、窗户、门、色彩与光线写成完整文字后生图，默认不附原片帧。用户特别要求该场景用截图参考时才附指定帧。人物遮挡处合理补全，不扩大房间或改变布局。
- 同一办公室的正反打是同一空间。必要时生成不同视角，但不把反打方向的家具硬搬到正面镜头。
- 没有建立全貌的门口只还原可见局部，不捏造整条走廊或建筑。
- 书籍、文件夹、盆栽、桌面纸张自然包含在场景中；不从对话推断原片没有展示的独立物品。

## 道具图

只提取真正参与剧情的物件：推动事件、关键动作所需、身份／线索／反转的载体，或需要跨镜保持明确外形的物件。每项在清单写出剧情用途和出现段落；普通餐具、装饰、背景陈设、无意提及的小玩意不单列，必要时随场景或人物描述呈现。是否被拿在手中不是唯一准入条件，须有剧情作用。

必要对象及完整提示词在第一阶段一并确认；已确认清单或用户明确全流程授权范围内直接执行，不重复询问。仅批准一个物件不扩展到全部陈设。道具成品提示词根据可见形态写材质、颜色、结构和尺度，通常为白背景单件图；剧情用途留在清单，不写进成品提示词。默认纯文字生图，截图例外遵从上节。

## 资产清单

在项目输出目录维护 `asset-manifest.json`，已有清单先读再更新，保留无关条目。结构可调整，至少包含：

```json
{
  "skill": "触手",
  "source_video": "原视频路径",
  "assets": [
    {
      "id": "稳定角色或场景标识",
      "type": "character",
      "name": "角色／场景名称",
      "status": "existing",
      "path": "可复用图片路径",
      "reference_paths": [],
      "reuse_notes": "已确认的身份／服装／角色映射"
    }
  ]
}
```

状态使用 existing、generated、pending_confirmation 或 skipped。不能仅凭名称相同认定可复用，要核对图片和本次要求。用户未要求修改的有效已有资产不重复生成。

按需记录每项资产的 `style_mode`（如live_action、3d、2d）、`layout`、基础资产／状态版本映射及最小补全说明，便于后续质检选择正确分支；复用旧图时不伪造其版式。3D项目的资产总表、新增清单与分类提示词顺序按3D文件执行，不把候选清单当成道具生成授权。
