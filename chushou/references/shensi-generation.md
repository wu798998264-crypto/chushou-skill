# 神思画布与媒体适配入口

本页区分**新版神思笔记**与**旧神思创作引擎**，不能把旧引擎中的笔记模式当成新版应用。未指定目标的新画布任务默认当前可用最新版神思笔记；用户明确指定的平台／实例／白板，以及正在继续的真实任务绑定优先。默认变更不迁移、重建或取消旧任务。

## 先识别协议，再操作

使用随包只读探测器 `scripts/shensi_canvas_probe.py` 动态发现本机实例；命令参数以 `--help` 为准。它只识别应用首页和协议，不创建笔记、读写用户文档或生成媒体。新版可能由Electron内嵌服务监听，不能只匹配node命令行中的固定端口。绑定保留非秘密协议类型与真实目标ID；会话令牌只在内存中使用，不打印、保存或随素材包分发。

```text
python scripts/shensi_canvas_probe.py --list
python scripts/shensi_canvas_probe.py --binding-file 本任务绑定.json
python scripts/shensi_canvas_probe.py --kind legacy --origin http://127.0.0.1:当前实际端口
```

探测绑定形如 `{"protocol":"notes","origin":"http://127.0.0.1:当前实际端口"}`，可另存真实笔记／文档ID；旧协议为 `legacy`。显式地址或绑定失效时不会偷偷改选另一实例。重新发现仅用于核验并恢复同一目标，不能把过期端口当永久身份。

- **新版神思笔记：** 首页会话标识 `shensi-session`，采用笔记本ID、`/api/state`、`/api/attachment` 与画布内草稿，读取 [shensi-notes.md](shensi-notes.md)。这是未指定目标时的默认适配。
- **旧神思创作引擎：** 首页会话标识 `shensi-session-token`，采用托管workspacePath、`/api/workspace/*`、独立generation-drafts，读取 [shensi-legacy-engine.md](shensi-legacy-engine.md)。随包 `scripts/shensi_bridge.py` 仅支持这一路；其 `--kind notebook` 不能连接新版神思笔记。
- **网页画布／其他协议：** 按 [canvas-adapters.md](canvas-adapters.md) 使用真实官方能力或浏览器UI。不能将任意本机网页都当神思，或向未识别服务发送会话凭据。

用户明确指定地址或既有绑定时核验它的真实协议再续接；不要因为发现另一个新版实例就改目标。同协议多实例且无法从当前目标消歧时局部询问。默认新版不可用时继续准备可迁移素材，说明尚未绑定；不静默退到旧引擎或私自启动缺少用户配置的源码服务器。应用更新后先核实能力与schema，不能根据窗口标题、`notebook`字段或版本号字符串猜接口兼容性。

## 两种神思共同遵守的制作规则

- 复刻原片必须真实入画布：**原视频 → 对应截图／参考帧 → 生成资产／分段卡片**。原视频最左侧，源帧在其右侧，资产居中，生成卡最右侧按段纵排；共享文件按身份复用，原生右口连下游左口。帧记录源文件SHA、实际PTS及段号，详见 [canvas-adapters.md](canvas-adapters.md)。来源边与模型引用分别登记，原帧不直接作为视频生成参考，原视频也不自动提交模型。
- 一段一张原生卡，完整提示词仅在生成操作栏；卡片写导航说明。默认16:9，时长按本段精确时长四舍五入（0.5向上），不压缩台词或静默回退参数。配置、参考编号及草稿字段以对应协议真实UI回读为准。
- 填写后收起操作栏，不明确关闭；保留用户主动关闭后的禁止自动展开设计。新状态最小增量保存，使用真实冲突戳，保留旧版、任务、结果、其他文档和用户改动；回读与刷新核验附件、连线、草稿及卡片点击恢复。
- 图片默认使用当前宿主内置图像生成工具；目标画布默认值不改变图片通道。外部生成图保留原始提示词与上游映射，登记实际图库，不伪造平台任务。道具图仍按用户既有要求先核对。
- 准备卡片不等于提交生成。视频须用户明确要求并在提交前核对本次具体模型、参数、全部分段、完整提示词、参考映射和音频；已有明确授权不反复确认。仅链接、说“继续”、连接画布或更新本规则不自动授权视频提交。

遵从 `prepared → bound → submitted → verified` 的实际状态。源文件、来源边或生成草稿未完成原生回读时列出具体缺项；当前仅核验源码时明确未进行导入实测，不能称已绑定。接口不支持的大文件／功能交付可迁移包并报告限制，不套用另一版接口或伪造已完成。
